# Instagram: ochilish postlari — matnlar (@citylanduz)

> Bu fayl — postlarning yagona manbasi. O'zgartirgandan keyin `npm run insta` (dev server `DEMO=1` bilan ishlab turishi kerak) — `docs/insta/postlar/` qayta yig'iladi.
> Slayd qatori: `- tur: … | sarlavha: … | matn: … | kadr: …`. Sarlavhada `*so'z*` — oltin urg'u (1–2 so'z). Format 1080 × 1350, faqat o'zbekcha, matnda emoji yo'q.
> **Kadr manbasi — sayt** (Foto rejimi grafikasi): `A` — oltin soat + maket (kunduzgi mavzular), `D` — tun. Kadr nomlari `insta/build.mjs` dagi `KADRLAR` ro'yxatida.
> Tur: `kadr` — sarlavha kadr ustida; `telefon` — telefon ramkasida bot ekrani; `raqam` — katta raqam (tanga); `shkala` — do'st taklifi sovg'alari; `chaqiriq` — oxirgi slayd.
> Halollik: niklar umumiy (`sening_niking`, `qoshnim`…), "N kishi yashaydi" kabi da'vo yo'q.

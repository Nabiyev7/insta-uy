# Raqobatchi tahlili: novaverse-uz.vercel.app (2026-11-24)

Yunusobod tumanining 3D nusxasi; Instagram niki + parol bilan kirish; uy quriladi (qavatlar, basseyn, garaj, vertolyot); taksi (haqiqiy brend mashinalar), o'yinlar zali, saylov, salyut (pullik), "eng boy" / "eng mashhur" reytinglar, stories kartochkasi, referal (1 do'st — hovuz+vertolyot, 3 — Malibu, 15 — Gelik). Pullik noyob joylar (metro, universitet, aeroport...), narxlar faqat botda, to'lov Stars yoki karta + chekni Direct'ga yuborish, admin qo'lda tasdiqlaydi.

## Ulardan olamiz
- Stories rasmiga havola stikeri + referal havola (2-bosqich).
- Uyga yurak va "Eng mashhur uy" reytingi (3-bosqich).
- Salyut (3-bosqich tanga bilan, keyin pul bilan).
- Noyob joylar: bitta joy — bitta ega, nik yonib turadi (to'lov ochilganda).
- Referal sovg'alari bezak ko'rinishida: 1 / 3 / 10 do'st (3-bosqich).
- Bepul nik joylari: avtobus, skameyka, daraxt (keyinroq, `KEYINGI.md`).

## Olmaymiz
- Haqiqiy brendlar va mashhur binolar nusxasi (mualliflik xavfi).
- Cheksiz qavatlar (bizda 2 qavat).
- Narxni yashirish, qo'lda to'lov tasdig'i, parol bilan kirish.

## Bizning ustunligimiz (reklamada aytiladi)

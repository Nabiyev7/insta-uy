# Telefonda sinov ro'yxati (egasi, Redmi)

> 12-qadamda (internetga chiqqandan keyin) to'ldiriladi. Har qatorni bajarib, yoniga ✅ yoki ❌ (nima bo'ldi) yozing.

## Bot va Mini App (6c-qadam)
- [ ] BotFather'da bot avatarini o'zingiz qo'ying (rasm — `docs/chat/` dagi logotip yoki o'zingiz tanlagan).
- [ ] Botga `/start` → birinchi xabarda «🇺🇿 O'zbekcha / 🇷🇺 Русский» tugmalari bor; tanlaganingizdan keyin hamma xabar faqat shu tilda.
- [ ] Nikni yozing → «Ha, to'g'ri» → pastda 6 ta tugma chiqdi: Shahar, Uy olish, Do'kon, Do'st taklif, Adminga yozish, Sozlamalar.
- [ ] «🏙 Shahar» → sayt **Telegram ichida** to'liq ekranda ochildi va **o'zi kirdi** (havola so'ramadi).
- [ ] Shaharni barmoq bilan pastga surganda ilova **yopilib ketmayapti**.
- [ ] Oyna ochiq paytda Telegram'ning yuqoridagi «Orqaga» tugmasi oynani yopadi (ilovadan chiqib ketmaydi).
- [ ] Tanga olganda yoki uy qurilganda telefon sal tebranadi.
- [ ] «🏡 Uy olish» → eng yaqin bo'sh joy ochildi; uy olgandan keyin `/start` → tugma «🏠 Uyim» bo'ldi va uyingizga olib boradi.
- [ ] «🛍 Do'kon» → saytda do'kon oynasi ochildi.
- [ ] Botning chap pastidagi **Menu** tugmasi ham «🏙 Shahar» — sayt ochiladi.
- [ ] «🌐 Brauzerda ochish» havolasi Chrome'da ochiladi va kiradi (15 daqiqa, bir marta).
- [ ] «⚙️ Sozlamalar» → tilni almashtiring → bot ham, sayt ham yangi tilda.
- [ ] «👥 Do'st taklif» → «📤 Do'stga yuborish» → Telegram'da do'st tanlash oynasi va tayyor matn chiqdi.
- [ ] (To'lov yoqilganda) Mini App ichida Stars bilan to'lash — botga chiqmasdan to'lov oynasi ochildi.
- [ ] Egasi uchun: `/stat`, `/hammaga` (matn → ko'rinishi → «Hammaga» → «Yuborish»), `/murojaatlar`, `/admin` ishlaydi; boshqa akkauntdan yozilsa — «Bunday buyruq yo'q».
- [ ] Oddiy akkauntda bot buyruqlari ro'yxatida `/admin`, `/stat` ko'rinmaydi.
- [ ] Kanal (`@citylanduz`): bot kanalda admin; kunlik post 20:00 da keldi (uy olingan kuni).

## Sayt
- [ ] Instagram bio havolasi → bot → «🏙 Shahar»: sayt ochiladi. Instagram ichki brauzerida ham, Chrome'da ham.
- [ ] Birinchi ochilish vaqti (soniya): ___. Shahar / Piyoda / Mashina rejimida qotish bormi (`?fps=1` bilan FPS ko'rsatkichi).
- [ ] Bepul uy olish → kamera uchadi → tabrik → uy ustida nik katta va o'qiladi; o'z uyingiz niki sariq.
- [ ] Kunlik bonus, kuchaytirish, do'kon (tanga va «Premium» bo'limlari), chat, tun rejimi, telefonni yotqizish.
- [ ] 10 daqiqa ishlatganda telefon qiziydimi, batareya necha % ketdi: ___.
- [ ] Mobil internet (Wi-Fi'siz) ham.
